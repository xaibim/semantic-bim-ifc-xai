# Research Positioning and Originality Boundary

## 1. Purpose

This document delimites the scientific position of the repository. It
separates current public evidence from planned work, avoids universal priority
claims, and frames the repository as a general public scientific research
artifact rather than a submission package.

This repository is a general public scientific research artifact. It is not
the application package, technical resource request or administrative
documentation of any specific funding or computing call.

## 6. Provisional Research Gap

The reviewed research landscape already includes BIM information retrieval,
multi-constraint querying, spatial reasoning, compliance checking, BIM
authoring, structured rule generation and agent-based workflows. The planned
research direction addresses a complementary methodological problem: the
combined evaluation of reproducible dataset governance, root-case leakage
control, resolvable IFC grounding, evidence supportedness, expected-negative
handling, safe recovery, capability and complexity stratification,
professional review, statistical analysis and computational measurement under
a common experimental contract. This is a provisional positioning statement,
not a universal priority claim.

## 9. Limitations

- sample20 is synthetic/sanitized and small;
- stored-record validation does not rerun model generation;
- the public evidence trace is structural;
- IFC schema participation is not professional-task suitability;
- the QLoRA pilot is a single bounded feasibility experiment;
- no comparative benchmark has been executed;
- no professional study has been completed;
- the literature positioning is provisional;
- this document is not a systematic-review result.
