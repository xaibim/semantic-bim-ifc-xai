## Boundary

The XAIBIM Space URL is the canonical public gateway. The bimaiblend URL is the registered interactive runtime endpoint. This gateway/runtime separation is an infrastructure arrangement. Link identity and dated availability do not establish deployment equivalence with this repository package. Equivalence remains PENDING_REMOTE_DEPLOYMENT_AUDIT until the deployment manifest records matching commit, file hashes and a post-deployment self-test.
