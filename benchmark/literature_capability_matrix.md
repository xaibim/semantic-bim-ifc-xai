This is a positioning matrix.
It is not a systematic review.
It is not a meta-analysis.
It does not demonstrate universal absence.
It is based on reference families already reviewed by the scientific team.
It prevents established capabilities from being claimed as original.

## Cross-Cutting Gap Considered by This Repository

This repository considers a broader combination of:

- governed dataset construction;
- root-case grouping;
- duplicate control;
- leakage control;
- frozen splits;
- resolvable grounding;
- claim-level supportedness;
- expected negatives;
- safe recovery;
- capability and complexity stratification;
- professional review;
- statistical uncertainty;
- computational measurement.

The combination is treated as a provisional research direction. This matrix
does not establish that no previous work contains any individual dimension or
combination of dimensions.
